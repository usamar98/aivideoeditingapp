# Cartoon style examples

These are illustrative AI-generated references for the cartoon style selector, not examples of a user's finished film. Created with the built-in image generation tool. They select the existing `3d`, `2d`, `anime`, and `clay` art directions; no generation model, pricing, or backend behavior changes.

Project assets are saved in `public/examples/cartoon-styles/`: `cinematic-3d.png`, `hand-drawn-2d.png`, `anime.png`, and `clay.png`. Original outputs are retained in the Codex generated-images directory. Images use Next.js responsive optimization when served.
